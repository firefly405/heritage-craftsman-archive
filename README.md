# 民间非遗手工艺人档案管理系统

传统工艺与手工艺人档案管理演示系统，包含艺人档案、作品管理、审核、竞价流程及本地模拟支付等功能。

## 技术栈

- 后端：Spring Boot、Spring MVC、MyBatis、MySQL
- 前端：Vue 3
- 可选支付流程：支付宝沙箱跳转或本地模拟；不用于真实收款

## 本地运行

项目需要 JDK 17、MySQL 8 和 Node.js。请先查看 `database-config.ps1.example`，在本机配置数据库连接；运行 `start.ps1` 时按提示设置初始管理员账号。也可以使用 `build.ps1` 构建项目。

支付宝沙箱功能需要由使用者自行配置沙箱应用 ID 和私钥。本公开源码快照不包含私钥、个人学籍信息、部署包或演示数据库数据；请勿将真实凭据提交到 Git。
